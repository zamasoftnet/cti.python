# cti.python

このリポジトリには、Python版CTIドライバーの世代別実装をまとめています。

- `python2/` : Python 2 系の実装
- `python3/` : Python 3 系の実装

## Python 3 のインストール（Git + pip）

Python 3 版は、リポジトリを直接指定してインストールできます。

```bash
pip install "git+https://github.com/zamasoftnet/cti.python.git#subdirectory=python3"
```

詳細は [python3/README.md](python3/README.md) を参照してください。
